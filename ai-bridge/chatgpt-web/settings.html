ChatGPT Web

直接使用网页登录。代码工具由 CC GUI 的本地执行器处理。此入口拒绝转发到 Codex 模型。

1 · 登录 ChatGPT

打开专用浏览器后登录；看到聊天输入框后关闭该窗口，等待自动验证。已有 Codex 登录不能代替这一步。

2 · 连接本地代码工具

在同一账号创建 Tunnel 和 Tunnel 所需 API key。Key 仅用于工具通道，不作为模型 API key。

然后打开 ChatGPT 应用设置，启用 Developer Mode，创建 Codex Native2 连接器，选择上述 Tunnel、Authentication: None，并允许所需工具操作。

首次连接会下载上游固定版本的 OpenAI tunnel-client 并校验 SHA-256。无需安装第三方桌面程序。

3 · 选择网页模型

此处的网页模型用于 ChatGPT Web 请求；CC GUI 底栏普通 GPT 模型及 Fast 设置不控制此入口。
